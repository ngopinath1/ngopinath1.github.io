# Nithin Gopinath — Personal Website

A simple static personal website built from Nithin's current resume and master experience/profile data.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — site content
- `styles.css` — styling and responsive layout
- `Nithin_Gopinath_Resume.pdf` — linked resume
